# LearnHub – Online Learning Platform

LearnHub is a responsive online learning platform built using React.js, JavaScript, HTML, CSS, and Vite.

## Features

- User Login and Registration
- Dashboard
- Course browsing and course details
- Learning progress tracking
- My Courses
- Wishlist
- User Profile and Settings
- Certificates

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite
